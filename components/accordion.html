What is a design system?
A design system is a collection of reusable components, patterns, and guidelines that teams use to build consistent, scalable products. It serves as the single source of truth for design and development decisions across your organization.
How do CSS custom properties work?
CSS custom properties (variables) are defined with a -- prefix in a selector, typically :root. They cascade like regular CSS properties and can be updated at runtime. Use them with var(--property-name).
Why use native HTML elements?
Native HTML elements like <details>, <dialog>, and form inputs come with built-in accessibility, keyboard navigation, and browser behavior — for free. They reduce JavaScript dependency and improve performance.

Is this design system free to use?
Yes, this design system is open source and free to use in any project. You can customize the CSS variables to match your brand.
How do I customize the colors?
Edit the :root block in variables.css. Change --color-primary, --color-secondary, and the surface colors to match your brand. Dark mode variables are in the [data-theme="dark"] block.
Does it support dark mode?
Yes — toggle dark mode by setting data-theme="dark" on the <html> element. All semantic tokens automatically switch to their dark-mode counterparts defined in the variables file.
Can I use this with a JavaScript framework?
Absolutely. The CSS variables and classes work with any framework — React, Vue, Svelte, Angular, or plain HTML. Import the CSS files and use the class names or variable tokens in your components.
